BADMINTON APP ver. 1.0 – PWA

Filer som ska ligga i roten på ditt GitHub Pages-repository:
- index.html
- manifest.webmanifest
- service-worker.js
- icon-192.png
- icon-512.png
- .nojekyll

Vid uppdatering på GitHub:
1. Öppna samma repository som du redan använder för Badminton-appen.
2. Ladda upp/ersätt filerna ovan i repositoryts rot.
3. Commit changes.
4. Vänta normalt någon minut och öppna din befintliga GitHub Pages-adress igen.
5. Om gammal version visas: stäng appen/webbläsaren helt och öppna igen. Service worker v1.0 rensar äldre cacheversioner.
