# Testmiljö – Badminton App, 18 oktober 2026

Paketet innehåller hela aktuella testmappen med diplom, serverstatistik och PDF-delning.

1. Packa upp ZIP-filen.
2. Uppdatera endast mappen test/ i ditt GitHub-repo med innehållet i paketets test/.
3. Behåll produktionsfilerna i repots rot.
4. Vänta tills GitHub Pages-publiceringen är klar och ladda om testsidan.

Testappen: https://scaniagotaxi.github.io/Fj-derligan/test/

Testappen har egna lokala inställningar men använder samma Supabase-databas som produktionen. Ingen ny SQL behövs för diplomet eller PDF-delningen. Befintliga databasfunktioner måste vara installerade för serverstatistik. SQL-filerna i test/ är installationsfiler och ska inte köras om rutinmässigt vid uppladdning.

PDF kan laddas ner eller delas via mobilens delningsfunktion till exempelvis WhatsApp.
