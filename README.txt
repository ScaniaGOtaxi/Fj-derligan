Badminton App v1.4 – FIX 39 – GitHub Pages

Ladda upp filerna i ZIP-arkivets rot till ditt GitHub-repository (packa upp ZIP först).
Gå till Settings > Pages > Build and deployment > Deploy from a branch.
Välj main och /(root), spara.
Din adress blir vanligtvis https://DITT-NAMN.github.io/REPOSITORY/

För lösenordsåterställning: lägg in GitHub Pages-adressen i Supabase Authentication > URL Configuration, som Site URL och/eller tillåten Redirect URL efter behov. Testa flödet.

OBS: Extern QR-kodsbibliotek laddas via CDN och kräver internet. Supabase-funktioner kräver anslutning och korrekt databas-/Auth-konfiguration.
