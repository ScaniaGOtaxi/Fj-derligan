UPPDATERA DEN ORDINARIE APPEN – 2026-10-13

Den här ZIP-filen innehåller den färdiga versionen från commit 09b5252.
Den inkluderar flaggor På/Av, spelarfigurer På/Av med separata namnrutor,
större centrerade namn och flaggor, och poängräkning som behålls vid rundbyte.

1. Packa upp hela ZIP-filen på datorn.
2. Öppna https://github.com/ScaniaGOtaxi/Fj-derligan och välj grenen main.
3. Stanna i repositoryts ROT (där index.html ligger), inte i test-mappen.
4. Välj Add file → Upload files.
5. Dra in de uppackade appfilerna, inte ZIP-filen eller en överordnad mapp.
   Ta med samtliga HTML-, JS-, bild- och manifestfiler samt README.md.
   UPPDATERA_GITHUB.txt är bara denna instruktion och behöver inte laddas upp.
6. Välj Commit changes direkt till main om GitHub ger dig det valet.
   Om en separat gren krävs: skapa och slå ihop dess pull request till main.
7. Vänta tills GitHub Pages har publicerat uppdateringen.
8. Öppna https://scaniagotaxi.github.io/Fj-derligan/ och ladda om med Ctrl+F5.
9. Om ett spel pågår: logga in vid behov och välj Återuppta senaste spel.

BEHÅLL test/-mappen och övriga befintliga filer. Radera inte repositoryt.
Ingen ny SQL behöver köras för denna uppdatering.
Testmiljön använder fortfarande samma databas men separata lokala inställningar.

Kontrollera kugghjulets Visa flaggor och Visa spelarfigurer samt att
poängtavlan fortsätter visas när du går till nästa runda.
